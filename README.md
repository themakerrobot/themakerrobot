## 🚀 시작하기

1. 기기의 **OS 버전**을 확인합니다.
2. [문서·예제 사이트](https://themakerrobot.github.io/openpibo-guide/)에서 **같은 버전**의 문서와 예제를 엽니다.
3. 기기의 **IDE**(Pibo Maker)에서 블록 또는 파이썬으로 실행합니다.

|---|---|---|---|
| Pibo | `260624v1` | [문서](https://themakerrobot.github.io/openpibo-guide/pibo/260624v1/index.html) | [예제](https://github.com/themakerrobot/openpibo-guide/tree/main/pibo/260624v1) |

## 🛠 Pibo Maker

기기 안에 들어 있는 개발 환경입니다. 브라우저로 접속해서 씁니다.

- **Tools** — 모터, 센서, 카메라, 마이크를 하나씩 켜 보고 값을 확인하며 로봇의 작동 원리를 익힙니다.
- **IDE** — 블록 코딩과 파이썬을 지원합니다. 이미지·오디오 재생, 파일 탐색기, 로그 보기가 함께 있습니다.

## 🧰 파이보 활용 소프트웨어

| 이름 | 하는 일 | 바로가기 |
|---|---|---|
| **파이보랩** | 기기 없이 온라인에서 파이보를 체험하고 활용합니다 | [열기](https://pibo-lab.themaker.workers.dev/) |
| **pibo-connect** | 교실의 파이보·파이브레인 여러 대를 브라우저 한 장으로 찾고, 같은 코드를 한 번에 실행합니다 | [저장소](https://github.com/themakerrobot/pibo-connector) |

## 🧠 AI 교육 소프트웨어

로봇 없이 브라우저나 PC만으로 AI를 배웁니다.

| 이름 | 하는 일 | 바로가기 |
|---|---|---|
| **Teach Lab** | 웹캠·마이크로 보여 준 것을 브라우저 안에서 바로 AI에게 가르칩니다 | [열기](https://themakerrobot.github.io/teach-lab/) · [저장소](https://github.com/themakerrobot/teach-lab) |
| **edge-lab** | 인터넷 없이 내 PC 안에서 도는 AI 학습 도구입니다 | [저장소](https://github.com/themakerrobot/edge-lab) |
