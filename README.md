# THE MAKER

> 인공지능 로봇 **파이보(Pibo)**를 개발한 로봇 스타트업 **서큘러스**의 교육 브랜드

THE MAKER는 학생들이 하드웨어, 소프트웨어, 서비스 개발 등 다양한 IT 기술을 직접 체험하며 자신만의 로봇 서비스를 만들 수 있도록 돕습니다. 로봇과 콘텐츠를 활용한 체험 교육으로 IT 기술을 재미있게 배울 수 있으며, `themakerrobot` repository를 통해 교육용 로봇 파이보를 제어하는 파이썬 패키지 **Openpibo**와 예제 코드도 함께 제공합니다.

---

## 🎓 이렇게 배웁니다

| 단계 | 내용 |
|:----:|------|
| **체험** | 로봇의 모터·센서·카메라를 직접 만지며 작동 원리를 익힙니다 |
| **코딩** | Block 코딩으로 시작해 Python으로 자연스럽게 넘어갑니다 |
| **제작** | 배운 기술을 모아 자신만의 로봇 서비스를 완성합니다 |

# Pibo Maker

로봇의 개별 기능을 체험·제어하는 **Tools**와 Python·Block 코딩 개발환경인 **IDE**를 제공합니다.

## 🛠 Tools

모터, 센서, 카메라, 마이크 등 로봇을 구성하는 하드웨어와 소프트웨어를 제어하는 도구를 제공합니다. 각 기능을 독립적으로 테스트하고 제어할 수 있어, 움직임을 시뮬레이션하거나 실제 모터를 동작시키고, 주변 환경을 감지하는 능력을 시험해 데이터를 확인할 수 있습니다. 이를 통해 로봇의 작동 원리를 이해할 수 있습니다.

## 💻 IDE

Python과 Block 코딩을 지원하며, 이미지 / 오디오 player, 탐색기, 로그 뷰어 등을 제공합니다. Python으로는 다양한 라이브러리를 활용해 로봇의 인공지능 기능을 개발할 수 있고, Block 코딩은 시각적 블록을 조합하는 방식이라 프로그래밍 경험이 없어도 쉽게 기능을 구현할 수 있습니다.
